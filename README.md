# Item API Project

This is a simple Spring Boot REST API to manage items.

## Features
- Add Item
- Get All Items
- Get Item By ID
- Update Item
- Delete Item

## Tech Stack
- Java
- Spring Boot
- Maven
- Postman

## How to Run

1. Open project
2. Run:

   mvn spring-boot:run

3. Server runs at:

   http://localhost:8080

## API Endpoints

POST   /items        → Add item  
GET    /items        → Get all  
GET    /items/{id}   → Get by id  
PUT    /items/{id}   → Update  
DELETE /items/{id}   → Delete
